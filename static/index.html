Simple Integration

One API call is all it takes

# Qualify a lead with a single API call
curl -X POST https://lead-qualification-engine-4ltk.onrender.com/api/v1/leads/analyze \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "company_name": "Acme Corp",
    "contact_name": "Jane Smith",
    "contact_email": "jane@acme.com",
    "message": "We need an enterprise solution for 500 users, budget approved for Q4",
    "source": "website_form"
  }'
